# Get Toasted

A phone-first browser arcade game about running the fryer station at [STL Toasted on the Hill](https://stlouistoasted.com/) in St. Louis. Three fryers, a rail of tickets, four flavors of toasted ravioli, and Matt watching. Endless, high score, busier the longer you last.

Read [SPEC.md](SPEC.md) for the design, [ART.md](ART.md) for the asset checklist, and [KICKOFF.md](KICKOFF.md) for how the first build gets made.

The code is MIT. The STL Toasted name, logo, menu and the owners' names belong to STL Toasted; this is a fan project made by two people who work there.
